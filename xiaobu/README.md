# 小步

焦虑、沮丧的时候打开它。它不劝你“别焦虑”，而是带你在 3 分钟内从“想”走到“做”，并记下做之前和做之后的感受，慢慢攒成你自己的证据。

## 打开后的流程

1. **先停 30 秒**：跟着圆圈呼吸三轮，给感受起个名字，给此刻打分（1–10）。
2. **分辨是哪种**
   - **A 在想别人怎么看我**：写下那个念头 → 分辨是事实还是解读（读心术、以偏概全、贴标签、放大、确有其事）→ 把“别人的看法”和“我是谁”分开 → 回到自己的价值，想起一次按它行动的经历 → 进入 B。
   - **B 想做但不敢开始**：选一件事 → 拆成 5 分钟内能做完的第一步 → 生成“如果-那么”计划 → 计时。
   - **C 说不清，就是烦**：选一个身体上的小动作（出门走 5 分钟、喝水、收拾桌角……）→ 计时。
3. **回来记录**：做完了、做了一部分，还是没做下去，都算一次尝试；再给此刻打分，可以写一句学到了什么。

## 三个页面

- **此刻**：入口，以及最近 7 天的尝试次数和情绪变化。晚上 8 点后如果当天还没有记录，会出现一句轻提醒。
- **回顾**：总尝试次数、做之前和做之后的情绪平均变化、价值行动账本、最常出现的感受和想法陷阱、最容易低落的时段。
- **我的价值**：编辑你的价值（默认是持续学习、不断迭代、勇敢、包容自己），维护“想做但还没做的事”，以及备份和恢复。

## 心理学依据

| 设计 | 依据 |
|---|---|
| 不说“别焦虑”，而说“焦虑可以在” | 压抑念头会使它反弹（Wegner）；接纳承诺疗法（ACT） |
| 给感受起名字 | 情绪标注（affect labeling，Lieberman） |
| 事实还是解读 | 认知行为疗法（CBT）的认知扭曲识别 |
| 回到自己的价值 | 依附型自尊（Crocker）；ACT 的价值澄清 |
| 聚光灯效应提示 | Gilovich 等，2000 |
| 拆到 5 分钟、小得可笑 | 微习惯（BJ Fogg） |
| 如果-那么计划 | 执行意图（Gollwitzer） |
| 先动起来，情绪会跟上来 | 行为激活疗法 |
| 计数尝试，不计成功率 | 过程目标；自我效能感（Bandura） |

## 文件

- `app.html`：应用本体，所有界面和逻辑都在这一个文件里。它也作为 claude.ai Artifact 发布。
- `build.py`：把 `app.html` 包装成独立 PWA 的 `index.html`（加上 manifest、图标和离线缓存）。修改 `app.html` 后运行 `python3 build.py`。
- `manifest.webmanifest`、`sw.js`、`icons/`：PWA 所需文件。

## 数据存在哪里

- 作为 claude.ai Artifact 打开时：保存在你账号下的私有存储（`data/users/<你的 id>/`），只有你自己能读写，换设备也能同步。同时在本机浏览器留一份副本。
- 作为独立 PWA 打开时：只存在这台手机的浏览器里（`localStorage`）。清除浏览器数据前，先到“我的价值 → 复制备份”。

## 自己托管成 PWA（可选）

把 `xiaobu/` 目录放到任意 HTTPS 静态托管（例如 GitHub Pages）。用手机浏览器打开 `index.html`，选择“添加到主屏幕”，之后就能像普通 App 一样全屏打开，离线也能用。
